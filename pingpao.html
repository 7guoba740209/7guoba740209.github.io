★ 平抛运动核心推论（一轮必背，附推导）

推论1位移偏角与速度偏角

tanθ = y/x = (½gt²)/(v₀t) = gt/(2v₀)
tanα = vᵧ/vₓ = gt/v₀ 　⇒　 tanα = 2 tanθ
速度方向偏角 α 是位移方向偏角 θ 的 2 倍。动画中 tanα 与 2·tanθ 实时相等，可当场验证。

推论2速度反向延长线过水平位移中点

从落点反向延长速度 v，交水平线于 x/2 处
设交点参数 u：y − u·vᵧ = 0 ⇒ u = y/vᵧ = t/2，
则 x截距 = x − u·vₓ = v₀t − (t/2)v₀ = x/2。
常用于平抛与斜面、碰撞、类平抛结合题的几何关系。

推论3飞行时间只由高度决定

t = √(2h/g)　（与 v₀ 无关）
竖直方向为自由落体，落地时间由下落高度唯一确定。

推论4水平射程

x = v₀ t = v₀ √(2h/g)
射程 ∝ v₀，∝ √h；在固定高度下与初速度成正比。

推论5落地速度

v = √(v₀² + 2gh)，　tanα = √(2gh)/v₀
落地速度由初速度与下落高度共同决定；vᵧ = √(2gh)。

推论6相等时间内 Δv 竖直向下

Δv = g·Δt　方向恒竖直向下
加速度恒为 g，任意两时刻速度矢量之差都在同一条竖直线上、等间距排列（速度矢量末端共线）。

推论7运动的分解（等时性）

水平：x = v₀t，vₓ = v₀（匀速）
竖直：y = ½gt²，vᵧ = gt（自由落体）
两个分运动独立、同时开始同时结束。这是所有平抛（及类平抛）问题的解题基础。

推论8轨迹方程

y = g·x² / (2v₀²)　（开口向下的抛物线）
消去时间 t 得到，说明平抛轨迹是抛物线；v₀ 越大轨迹越"平缓"。
