三维受力分解交互动画

力学「两级正交分解」范式演示：氦气球题 + 耙索题，两题共用同一套分解结构。
纯 Canvas 2D 手写三维管线，无需插件，手机/电脑浏览器均可直接播放。
制作人：尤溪一中物理组
绳拉力 T 的两级正交分解新版推荐
新增底部两个 2D 正视小图 + 右侧「分解层级」逐级展开按钮。
① 级：T = T⊥（指向另一球的水平力）+ T∥（重力·阻力平面内斜向下的力）
② 级：T∥ = Tx（指向运动方向的水平力）+ Tz（竖直向下的力）
两图把每一级画成真正矩形 / 直角三角形，几何关系一目了然。
耙索拉力 F 的两级正交分解新版推荐
2025·广州质检「两绳拉耙」情境：等边三角形 AO₁B、绳索面倾角 30°、两绳拉力均 F。
① 级：F = F∥（倾斜绳索面内）+ F⊥（指向另一耙索）
② 级：F∥ = Fx（向前）+ Fz（向上）；两绳总前向 = 3F/2（摩擦，选 C），总合力 F√3（选 B）。
